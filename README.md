# Video Chat Room

Веб-приложение для группового видеозвонка до четырёх участников. React-клиент, Node.js/Express, Socket.io для сигналинга и чата, WebRTC mesh для аудио и видео.

## Что нужно для запуска

- Node.js `>=22.12.0 <25` (рекомендуется версия из `.nvmrc`);
- npm `>=10`;
- Chrome, Firefox или Edge 100+;
- для камеры и микрофона — `localhost` либо HTTPS: браузеры не выдают `getUserMedia` на обычном HTTP-адресе.

На чистом окружении установите строго зафиксированные зависимости:

```bash
npm ci
```

Для локальной разработки:

```bash
npm run dev
```

После запуска откройте `http://localhost:5173`. Vite обслуживает клиент, а Socket.io/HTTP-сервер работает на `http://localhost:3000`.

## Как пользоваться

1. Введите своё отображаемое имя (до 30 символов).
2. Создайте новую комнату или вставьте ID комнаты и войдите.
3. Скопируйте ссылку комнаты и отправьте её приглашённым. Войти по ссылке может любой, кто её получил: авторизации и ролей нет.

Комната вмещает не более четырёх вкладок/участников. Одинаковые имена разрешены, но каждая вкладка считается отдельным участником. Если последний участник ушёл, комната и её история удаляются; повторный вход по той же ссылке создаёт пустую комнату.

Камера и микрофон включаются при входе, если браузер дал доступ. При отказе, отсутствии устройства или отключённой камере пользователь остаётся в комнате, а участники видят заглушку. Камера освобождается при выключении; включить её снова можно соответствующей кнопкой. При потере устройства выберите/разрешите его в настройках браузера или ОС и войдите заново.

## Ограничения MVP

- Медиа передаётся напрямую между браузерами через WebRTC mesh; сервер медиа не передаёт и не записывает.
- Используется публичный STUN. TURN отсутствует, поэтому у пары пользователей за строгим NAT видео или аудио может не установиться.
- Чат хранится только в памяти текущего процесса: последние 500 пользовательских и системных сообщений суммарно. После удаления комнаты или рестарта сервера история пропадает.
- Имя, комната и сессия не сохраняются в браузере. Перезагрузка — новый вход.
- При неожиданной потере сети или рестарте сервера клиент очищает локальные медиа и peer connections, показывает «Соединение с сервером потеряно. Войдите снова.» и не подключается сам. Нужно войти вручную.
- Ссылка комнаты — открытое приглашение, а не средство аутентификации. Не публикуйте её в открытом доступе.

## Проверки

```bash
npm run lint
npm run test:unit:coverage
npm run test:integration
npm run test:browser
npm run test:production-smoke
npm run test:soak
```

`test:browser` использует Playwright. Если браузер Playwright ещё не установлен, выполните `npx playwright install chromium` (на Linux CI — `npx playwright install --with-deps chromium`).

`test:production-smoke` собирает SPA и проверяет, что `/healthz`, Socket.io и deep link `/room/:roomId` работают на одном production-порту.

## Production и эксплуатация

Production запускается командами:

```bash
npm run build
npm start
```

Сервер слушает `0.0.0.0:$PORT`, отдаёт SPA, `/healthz` и Socket.io на одном origin. Инструкция по Render, обязательные переменные окружения и проверка домена/TLS — в [render-deployment.md](prds/video-chat-room/render-deployment.md). Runbook ручного релиза и rollback — в [operations-runbook.md](prds/video-chat-room/operations-runbook.md).
